# ☪️ Quran Audio Player

A modern and responsive Quran Audio Player built with HTML, CSS, and JavaScript.

The project allows users to listen to the Holy Quran **Ayah by Ayah**, while displaying the currently playing Ayah on screen.

## 🌐 Live Demo

🚀 **[View Live Website](https://mohamedashraf-a.github.io/Quran/)**

## ✨ Features

- 📖 Browse all 114 Surahs
- 🎧 Ayah-by-Ayah Quran playback
- 📝 Display the currently playing Ayah
- ▶️ Play / Pause
- ⏮️ Previous Ayah
- ⏭️ Next Ayah
- 🔄 Autoplay
- 🎙️ Multiple Quran reciters
- 🔊 Volume control
- 🔇 Mute / Unmute
- ⏱️ Audio progress and duration
- 📱 Fully responsive design
- 🇸🇦 Arabic RTL interface
- 🌙 Modern and elegant UI
- ⚡ No page reload while changing Surahs or Ayahs

---

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- REST API
- HTML5 Audio API
